# 迷你牧场 · 网页版（矿石镇萌版 3D）

参考任天堂《牧场物语：矿石镇的小伙伴们》玩法制作的**纯前端**牧场经营小游戏，画面为固定俯视角 Q 版 3D（大眼高光、柔和描边、四季色调）。
**零依赖、零构建、可离线**：双击 `index.html` 即可在浏览器中直接游玩，也可直接部署到 GitHub Pages。

---

## 一、如何运行

| 方式 | 操作 |
| --- | --- |
| 最简单 | 双击 `index.html`，用 Chrome / Edge / Firefox 打开即可离线游玩 |
| Windows 启动器（推荐） | 双击 `启动迷你牧场_自动端口.cmd`：自动挑一个空闲端口起本地服务并打开浏览器 |
| 固定端口启动器 | 双击 `启动迷你牧场.cmd`：固定使用 8080 端口 |
| 命令行 | 在本目录执行 `python -m http.server 8081`，浏览器访问 `http://127.0.0.1:8081/` |

> 用本地服务器方式打开时，存档（`localStorage`）更稳定。手机访问可在同一局域网内用 `python -m http.server 8081 --bind 0.0.0.0`，再用手机浏览器打开 `http://<电脑局域网IP>:8081/`。

## 三、玩法说明

### 1. 核心循环
「农田播种 → 浇水施肥 → 收获入库 → 商店出售 → 攒钱扩张 → 结束一天」。
所有操作即时结算，存档自动写入浏览器 `localStorage`，关闭页面不丢失。

### 2. 季节系统
每 **30 天**轮换一次季节（春 → 夏 → 秋 → 冬），换季当日牧场日志与界面提示会标出进入的新季节。
每个季节有 **专属作物 + 2 种观赏花卉**；花卉同样播种生长，成熟后按高价出售。
货架与可播种列表随季节自动更新，跨季不换种会白忙一季。四季作物与花卉合计 21 种：

| 季节 | 作物 | 观赏花卉 |
| --- | --- | --- |
| 春 | 萝卜、土豆、黄瓜、草莓 | 郁金香、三色堇 |
| 夏 | 番茄、玉米、西瓜 | 向日葵、牵牛花 |
| 秋 | 茄子、胡萝卜、南瓜、红薯 | 菊花、大丽花 |
| 冬 | 白菜、白萝卜 | 一品红、山茶花 |

### 3. 农田（6 × 4 = 24 块地）
| 操作 | 说明 |
| --- | --- |
| 耕地 | 荒地无法播种，需先开垦；也可「开垦全部」 |
| 播种 | 优先消耗种子袋，无袋则自动扣金币购买 |
| 浇水 | 每块地每天最多 3 点水分；缺水当天停止生长 |
| 施肥 | 拥有肥料优先消耗，否则花金币购买，可叠加，加速生长 |
| 收获 | 成熟后地块高亮，一键收获全部 |

**多阶段作物**：每株作物有 4 个生长阶段，田间 3D 模型随阶段变化（幼苗 → 长茎 → 展叶 → 结果 / 开花），成熟花卉以一丛三朵的形态呈现，可直观判断长势。

### 4. 养殖与动物爱心
- 商店可购买 4 种家畜：小鸡（1500G）、奶牛（5000G）、绵羊（4000G）、安哥拉兔（3000G），喂食后按各自周期蓄产，产物可收取出售；数据层另预留三花猫、羊驼的配置，当前版本商店暂未开放购买。
- **小狗「小旺」**（开局即在牧场）：每天可喂食，并可切换「守夜 / 休息」。吃饱且守夜时，夜间野狗袭击概率由 22% 降至 8%；没喂饱或未守夜则保护失效。小狗会在牧场里自主走动遛弯。
- **马**（5000G）：买下后在马厩可骑乘 / 下马，骑乘状态会同步到牧场场景；不骑乘时会在围栏内自主走动。
- **点击动物撒娇**：点击动物会按爱心值触发撒娇动作，并在其头顶显示 **灰 / 黄 / 红** 三档爱心（低心灰、中心黄、高心红）。
- **产物分级**：S / M / L / G / P / X，倍率 1.0 / 1.5 / 2.2 / 3.2 / 5.0 / 8.0。S 对应爱心 1~3、M 对应 4~7、L 对应 8 以上；G 需 L 且比赛夺冠，P 需 G 且放牧累积 547 小时，X 需 P 且 1/255 概率。

### 5. 动物疾病与药品
- 恶劣天气（降雨、暴风雨、台风、暴雪）下，户外动物可能感冒生病；生病动物停止产蛋 / 产奶并持续掉状态，需用药治愈。
- **每种动物一款专属药**（小鸡暖身草药 400G、奶牛健胃药 1500G、绵羊驱寒药 1200G、兔兔清鼻滴剂 900G、猫猫小鱼药丸 1000G、羊驼安神膏 1800G），在商店「道具」页购买后进入药品库存，在牧场对生病动物点 💊 即可治疗。
- **定价红线**：所有药价均不超过该动物售价的三分之一（脚本内置自检，超限会在控制台告警）。
- **马厩动物（马、小狗、老鹰、鸬鹚）不会生病**，不必买药。

### 6. 放牧与狼袭风险
- 牧场页「🐾 放牧」可把动物放到户外：**放牧每天增加爱心**（每只 +5 好感点），放牧满 5 小时可当餐免喂。
- 坏天气（暴风雨 / 台风 / 暴雪等）不适合放牧，动物会被强制召回。
- **天黑（睡觉）前请点「收回」**：过夜未收回的放牧动物存在风险——狼群闯入时 25% 概率**叼走 1 只**（不可逆损失），未得手的夜晚则让在外动物**全体掉 6 点爱心**；小狗吃饱并守夜可把闯入概率降到 8%。（暴风雨夜动物会被强制召回，不算在外过夜；住马厩的马、小狗、老鹰与鸬鹚不在狼的猎物范围内。）界面会明确提示当夜结果。

### 7. 天气系统与灾难天气
共 6 种天气：晴、降雨、暴风雨、干旱、台风、暴雪。
- 雨天自动为农田补水；
- 干旱使作物停止生长；
- 暴风雨 / 台风 / 暴雪属于**灾难天气**：发生时按地块随机抽取受损作物并直接摧毁，**损失比例为在种作物的 10%~50% 随机**（只要有作物，至少损失 1 块），并弹出损失明细弹窗（含损失比例、受损作物清单，弹窗打开时游戏时间暂停）。
- **每季至少 1 次灾难天气**：系统做保底安排（季末若当季仍未出现灾难则强制安排），季节专属灾难池为：春 暴风雨 / 夏 台风·暴风雨 / 秋 暴风雨 / 冬 暴雪。
- 天气页提供 **未来数日预报**（含灾害预警标记）与 **牧场日志**；
- 建成 **天气祭坛** 后可主动改变天气（可升级，高阶可锁定非灾害天气）；
- 建成 **温室大棚** 后，室内作物免疫天气灾害与换季枯萎，被护住的作物会从损失明细中扣除。

### 8. 宠物伙伴：老鹰与鸬鹚
在马厩「飞禽伙伴」处领养，同时也是比赛的前置条件：

| 伙伴 | 价格 | 日常能力 |
| --- | --- | --- |
| 老鹰「小旋」 | 8000G | 每天清早盘旋巡视农田，**叼走田鼠害虫**（每天最多 4 只，害虫会让作物停止生长）；**雨天 / 台风 / 暴雪等恶劣天气不外出**，此时只能手动捉虫或等虫子自行散去 |
| 鸬鹚「小黑」 | 6000G | 可派去**鱼塘抓鱼**；每天有**体力上限（3 点）**，每次下水消耗 1 点，体力每天回满；在马厩界面与农田栏目均可查看当日体力与已抓鱼数量 |

两只伙伴均为**正式 3D 模型**：老鹰在牧场上空低空盘旋巡视（航线已避开 HUD 区域，任何视角都不会被界面遮挡），鸬鹚守在鱼塘边待命；马厩与图鉴面板使用配套的 3D 图标（`assets/icons/pet_eagle.png`、`pet_cormorant.png`）。

### 9. 鱼塘与淡水鱼（8 种）
- 鱼塘位于牧场东侧，**在「农田」栏目本季可种列表下方以纯文字展示**。
- 塘中只养 **8 种淡水鱼**，不含任何海鱼与海滩采集物：

| 鱼种 | 稀有度 | 基础售价 | 鱼种 | 稀有度 | 基础售价 |
| --- | --- | --- | --- | --- | --- |
| 鲫鱼 | ★1 | 120G | 鲶鱼 | ★2 | 210G |
| 鲤鱼 | ★1 | 150G | 黄颡鱼 | ★3 | 280G |
| 鲢鱼 | ★2 | 190G | 黑鱼 | ★3 | 300G |
| 草鱼 | ★2 | 200G | 鳜鱼 | ★4 | 460G |

- 派鸬鹚下水抓鱼：消耗牧场体力 3 点 + 鸬鹚体力 1 点，耗时 30 分钟，一次叼回 1~2 条；**抓到的鱼可直接售卖，并计入海产图鉴**。
- 8 种鱼均配正式 3D 图案（`assets/icons/fish_carp.png`、`fish_crucian.png`、`fish_grasscarp.png`、`fish_silvercarp.png`、`fish_snakehead.png`、`fish_catfish.png`、`fish_yellowcat.png`、`fish_mandarin.png`），并与侧边河流钓场共用同一套鱼图标。

### 10. 商店
商店为纵向卡片式版块：当季种子、动物、工具升级（铜 → 银 → 金 → 秘银 → 贤者）、道具与设施、加工链、兑换商店、设施升级（天气祭坛 / 温室大棚）。
出售不在商店进行：从牧场页顶部「背包 N 件」进入背包页，可单品出售或按类目一键出售，**按物品基础价 × 品级倍率结算**（S 1.0 / M 1.5 / L 2.2 / G 3.2 / P 5.0 / X 8.0）。
道具页出售肥料、精饲料、**六种动物专属药**、修围栏与三种加工机；**兑换商店**用矿石或高品质产物兑换体力上限提升、爱心道具、神秘种子等限定商品。
**围栏与加工机**除了购买本身，还各自带一条 **5 级升级线**（入口就在商店对应卡片上，按钮会直接标出下一级所需金币与矿石），详见「加工链与 5 级升级体系」一节。

### 11. 比赛活动与节日日历
- **比赛活动**（每月固定 2~3 天，日期互不连续，四季均有）共 6 种：赛马比赛、飞鹰比赛、鸬鹚抓鱼比赛、钓鱼比赛、沙雕比赛、篝火比赛。参赛消耗体力与时间，按名次发放奖金，部分比赛附带全体动物爱心加成与海产奖励；比赛有前置条件（赛马需先买马、飞鹰需领养老鹰、鸬鹚抓鱼需领养鸬鹚、钓鱼需钓竿）。
- **节日日历**：日历页展示当月节日（春 / 夏 / 秋 / 冬 各 3~4 个，如年糕大会、赛马大会、牛祭、羊祭、烟花大会、收获祭、星夜祭、除夕等），节日当天参加可领取金币、种子或全体动物爱心奖励。

### 12. 矿洞
多层矿洞递进探索，可获取矿石等稀有产出（泉矿场常时开放，湖矿场冬季湖面结冰后开放）；镐子等级越高，同一矿层可挖掘的次数越多，下矿消耗体力与时间。矿石是工具升级、设施建造与兑换商店的硬通货。

### 13. 海滩与海产图鉴
可前往海滩获取海产，收集后录入 **海产图鉴**，补全图鉴是本作的收集向目标之一。

### 14. 加工链与 5 级升级体系（围栏 / 三种加工机）
**奶酪机 / 蛋黄酱机 / 毛线机** 可将牛奶、鸡蛋、羊毛等畜产品加工为高价值成品（奶酪 / 蛋黄酱 / 毛线球）再出售；三台机器各 20000G，在商店「道具与设施」购买，购买后 **3D 造型会直接摆到牧场里**。

#### 14.1 五级阶梯与材料需求

等级名统一为 **Lv1 木制 → Lv2 加固 → Lv3 精工 → Lv4 白银 → Lv5 传说**（每级配色/造型不同，等级越高越华丽）。

| 目标等级 | 围栏升级（金币 + 矿石） | 加工机升级（金币 + 矿石） |
| --- | --- | --- |
| Lv1 → Lv2 | 6,000G | 9,000G |
| Lv2 → Lv3 | 18,000G + 铜矿石 ×3 | 26,000G + 铜矿石 ×5 |
| Lv3 → Lv4 | 45,000G + 银矿石 ×5 | 65,000G + 金矿石 ×6 |
| Lv4 → Lv5 | 110,000G + 秘银 ×6 + 贤者之石 ×2 | 160,000G + 秘银 ×8 + 贤者之石 ×3 |

规则要点：
- **1 → 2 级只花金币**；3 级起需要矿石，且数量逐级增多、种类越来越稀有（铜 → 银 / 金 → 秘银 + 贤者之石），矿石需去矿洞开采。

- 围栏的**段数**与**等级**是两件事：段数上限 **10 段**（在商店逐段加固，每段 500G，降低野狗袭击概率），等级（Lv1~5）在提升外观的同时进一步压低野狗夜袭风险（无围栏 22%，Lv1~2 为 8%，Lv3~4 为 6%，满级 Lv5 降至 4%）；段数与等级都会同步到牧场场景中的实际围栏造型。
- 升级按钮会实时显示「下一级所需金币 + 矿石」，材料或金币不足时点击会得到明确提示；满级后按钮变为「已满级 Lv5」徽标。
